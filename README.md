# taki-onepage-demos

Day-2 income-stream asset (2026-10-15): demo one-page website previews built BEFORE
contact for KC-metro local-service businesses with no working website (Taki model).

- One folder per prospect, each serving an `index.html` demo preview.
- Built by content edits on `bootform/one-page-site` (MIT). Prospect verification
  records live in the ops workspace under `hidden_files/day-02/prospects.md`.
- Every demo page carries: `noindex,nofollow` meta, a prominent C2R Marketing demo
  banner with a report/takedown mailto, plain-text business name only (no logos).
- $95 one-time setup fee if the business keeps the site. Not a subscription.
